TIGRESS V3
- Full-screen sticky tiger hero with smoothed scroll progress.
- IntersectionObserver reveals from four directions with stagger.
- Arabic/English-aware brand marquee.
- Font Awesome UI icons.
- Reference-style dark service cards and patterned 3-column footer.
- assets/footer-pattern.svg is the SVG supplied in chat.
- assets/clients contains local fallback images so the site never breaks offline.

- Put the real contact values in js/config.js. Floating WhatsApp/phone buttons remain hidden until values are supplied.
- The original font binaries are intentionally not bundled; copy your licensed fonts into /fonts using the filenames already referenced by CSS.
